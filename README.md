# Modern E-Commerce Frontend

A responsive e-commerce interface demonstrating product discovery, filtering, wishlist state and a persistent cart.

## Features
- Product grid
- Search
- Category filtering
- Wishlist interactions
- Cart state
- LocalStorage persistence
- Responsive mobile/desktop UI
- Accessible buttons and form controls
- API-ready product data model

## Tech Stack
React · TypeScript · Vite · Lucide React · CSS

## Run
```bash
npm install
npm run dev
```

## Frontend concepts demonstrated
Client-side state management, derived filtering, browser persistence, responsive layouts, reusable product components and interaction design.
